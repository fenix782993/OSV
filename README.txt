ОСВ — система аттестации v2

Файлы: main.py, requirements.txt, render.yaml, static/index.html, static/style.css, static/app.js. Положите banner.jpg в корень рядом с main.py.

Render Build Command: pip install -r requirements.txt
Render Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
Переменные: APP_SECRET (длинная случайная строка), OWNER_PASSWORD (задайте свой пароль владельца), COOKIE_SECURE=1. Для уже существующей базы выполнены добавочные миграции при старте; перед обновлением желательно сделать резервную копию osv.db.

Владелец: Fenix_Dinero. Первый пароль берётся из OWNER_PASSWORD при первом создании аккаунта владельца. Если владелец уже есть в базе, его существующий пароль сохраняется.

Регистрация: пользователь выбирает запрашиваемую должность. Пока владелец не одобрит её, аккаунт видит статус ожидания и не может подать заявку на тест. После одобрения должности пользователь отдельно подаёт заявку на аттестацию. Только владелец одобряет/отклоняет обе заявки. Доступ к вопросам и отправке ответов проверяется сервером.

Панель владельца: Должности, Заявки на тест, Участники, Результаты, Журнал, Вопросы. События входа/выхода, регистрации, заявок, решений и попыток фиксируются.
