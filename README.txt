ОСВ — портал аттестации

Запуск локально:
  pip install -r requirements.txt
  uvicorn main:app --host 0.0.0.0 --port 8000

Render:
  Build: pip install -r requirements.txt
  Start: uvicorn main:app --host 0.0.0.0 --port $PORT
  Runtime: Python 3.12 (рекомендуется)
  Environment: APP_SECRET=<длинный случайный секрет>, OWNER_PASSWORD=<пароль владельца при первом создании>

Владелец: Fenix_Dinero. Если база уже содержит владельца, его текущий пароль сохраняется.
SQLite хранится в osv.db рядом с main.py; для Render используйте Persistent Disk, смонтированный на каталог проекта, иначе данные могут пропасть при пересоздании инстанса.

Аттестация:
- Сотрудник подаёт заявку, после допуска запускает письменную аттестацию.
- Система выбирает случайные 33 вопроса из активной базы (не менее 33).
- Сотрудник вводит развёрнутые ответы; работа отправляется на проверку.
- Инструктор, начальник или владелец выставляет каждому ответу 1 (✓) или 0 (✕), затем завершает проверку.
- Результат сохраняется как 33 вопроса, проходной порог 28 отметок.
- Массовая загрузка вопросов доступна в панели управления, по одному вопросу на строку.

Перед заменой работающего проекта сделайте резервную копию базы osv.db. Архив не переносит существующую базу данных.

Дополнительные разделы:
- Служебный чат: общий канал для подтверждённого состава, закрытый чат руководства (владелец/начальник/заместители) и личные сообщения.
- Личное дело: сведения сотрудника, история аттестаций, кадровые записи о поощрениях/выговорах/замечаниях и журнал изменений должности/звания.
- В панели показываются сводные счётчики состава, заявок, проверок и кадровых записей.
- Начальник и владелец могут вносить кадровые записи; владелец защищён от удаления. Инструктор/заместитель/начальник имеют доступ к проверке работ и базе вопросов.


Обновление: регистрация требует игровой ID (маску); аттестация доступна только стажёрам; заявки на допуск рассматривают инструкторы и руководство. Нормативные ссылки доступны в верхнем меню.
