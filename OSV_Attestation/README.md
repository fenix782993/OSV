# ОСВ — портал аттестации (Amazing RP)

Готовый адаптивный сайт на FastAPI + SQLite. Включает регистрацию, вход, публичный состав, аттестацию из 33 вопросов, настраиваемые правильные ответы и баллы, порог 28, журнал результатов и панель управления.

## Локальный запуск (Windows CMD)
```cmd
cd OSV_Attestation
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
set OWNER_PASSWORD=ВашНадёжныйПароль
set APP_SECRET=любая-длинная-случайная-строка
uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000

Первый владелец: **Fenix_Dinero**, должность «Инструктор ОСВ», права владельца. При первом запуске пароль берётся из `OWNER_PASSWORD`; локальный запасной пароль `ChangeMe_123!` замените сразу. Владелец может назначать должности и управлять тестом. Инструктор управляет вопросами и видит результаты, но должности назначает только владелец.

## GitHub + Render
1. Распакуйте ZIP и загрузите всё содержимое репозитория в GitHub.
2. В Render выберите **New → Blueprint** и подключите репозиторий с `render.yaml`, либо создайте Web Service вручную.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Добавьте переменные `OWNER_PASSWORD` (надёжный пароль владельца), `APP_SECRET` (длинная случайная строка) и `COOKIE_SECURE=1`. `PYTHON_VERSION=3.12.8`.
6. Для сохранения SQLite между перезапусками Render подключите Persistent Disk и используйте путь к базе на диске. Для простого бесплатного тестового деплоя база может сбрасываться при пересоздании/перезапуске инстанса; для постоянной эксплуатации используйте PostgreSQL или диск.

## Использование
- Пользователь регистрируется с игровым ником, должностью и паролем. Новая учётная запись получает роль «Кандидат».
- Владелец `Fenix_Dinero` через «Управление → Участники» назначает должности: начальник ОСВ, заместитель, стажёр, инструктор, инспектор, старший инспектор.
- Во вкладке «Вопросы» добавьте ровно 33 активных вопроса. Варианты вводятся каждый с новой строки, правильный ответ задаётся индексом с нуля (первый = 0). Баллы задаются отдельно для каждого вопроса. Сумма баллов должна быть не менее 28, чтобы порог был достижим.
- После прохождения пользователь сразу увидит баллы и итог. Прошедшим показана ссылка VK `karl_limansky2025`.
- Эмблема ОСВ нарисована средствами CSS/HTML. Свой баннер/изображения можно положить в `static/` и подключить в `static/index.html`.

## Важно
Это игровой фан-сайт сообщества, не официальный ресурс Amazing RP. Перед публичным запуском задайте сильные секреты и пароль, настройте постоянное хранилище, резервные копии и HTTPS. Не публикуйте `osv.db`, `.env` или пароли в GitHub.
