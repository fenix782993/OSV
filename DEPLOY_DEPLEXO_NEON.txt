OSV BLUE COMMAND V18 — DEPLOYMENT NOTES

REPOSITORY CONTENTS
Keep main.py, requirements.txt, and the static/ folder at the repository root.

DEPLEXO BUILD COMMAND
pip install -r requirements.txt

DEPLEXO START COMMAND
uvicorn main:app --host 0.0.0.0 --port $PORT

ENVIRONMENT VARIABLES
DATABASE_URL = full pooled PostgreSQL connection string from Neon (recommended)
APP_SECRET = long random private secret
OWNER_PASSWORD = strong initial owner password, used only when Fenix_Dinero is first created
COOKIE_SECURE = 1 when the site is served over HTTPS

NEON SUPPORT
The application reads DATABASE_URL, or NEON_DATABASE_URL as a fallback. The value must be the full PostgreSQL connection string, not an API token. Keep any unrelated token variable already configured in Deplexo unchanged. Never put real secrets in GitHub or this ZIP.

VERIFY AFTER DEPLOYMENT
Open /api/health. Expected response includes:
  "status": "online"
  "database": "postgresql"

Do not delete any old database or hosting service until you have verified login, users, roles, question bank, applications and exam history against the Neon database.

WHAT CHANGED IN V18
- Individual and department-wide re-attestation for owner, head, deputy and instructors.
- A blacklist for any nickname (including nicknames not registered on the site), with a reason, creator and timestamp.
- Blacklist visible to owner, head, deputy and administrators; only owner, head and deputy can add/remove records.
- Three-minute server-enforced timer per question, sequential question navigation, persisted position on reload, and app navigation lock during an active exam.
- Scrollable sidebar with fixed bottom account/status controls.
