DEPLOY IN DEPLEXO
1. Extract this ZIP.
2. Upload/commit all contents of this folder to the ROOT of the existing GitHub repository used by the Deplexo app. Do not put the project inside an extra nested folder.
3. Build command: pip install -r requirements.txt
4. Start command: uvicorn main:app --host 0.0.0.0 --port $PORT
5. Preserve existing Deplexo secrets/environment variables. Ensure DATABASE_URL is the full Neon PostgreSQL connection string (not a Neon API token). The app also accepts NEON_DATABASE_URL as a fallback.
6. Keep APP_SECRET unchanged if you want existing signed cookies to remain valid; the existing cookies may still expire naturally. OWNER_PASSWORD is only used if Fenix_Dinero is created for the first time.
7. Do not replace/remove the current Neon database or change the connection string. The application will add missing tables/columns through its existing startup migration.
8. When deployment finishes, open /api/health and verify "database":"postgresql". Then test owner login, an ordinary staff account, role permissions, question bank, attempts and blacklist.

NETWORK / VPN NOTE
The web interface itself no longer loads Google Fonts or the large banner from external services. If the entire Deplexo host/app URL still fails to open without VPN, that is a host/DNS/ISP routing issue and cannot be fixed by CSS or Python changes; compare whether the base Deplexo domain opens on the same connection.

SAFETY
Never commit real DATABASE_URL, APP_SECRET or OWNER_PASSWORD to GitHub. Keep them only in Deplexo Environment Variables. Do not delete old deployment/database until the new app is verified.
